# ORB wiki

## Breadcrumb stack

`Workspace / ORB / Segment / Repository / Pull request / Evidence / Memo`

Each dataset lives in its own memo widget with a concise request overview. `TASKCONTRACT-POINT-AUTOSYNC` labels a proposed handoff contract, not a running sync service. The registry index describes expected classifications and sync states. The dashboard currently renders sample records from `packages/registry/src/index.ts`.

## Intended integrations

Read-only GitHub/GitLab adapters can populate PRs and checks. A device-side companion would need explicit user consent, scoped storage, and platform-supported backup APIs. Never scan browser, app, credential, or device data without permission. Cloud-backed AndroidX saved-game behavior is not implemented in this web frontend.
